# 纳瓦尔 · 播客访谈视频 全段提示词

写实播客访谈视频，16:9 横屏，专业电影摄影机拍摄，固定机位中景，约 3 秒。

【环境】一间温暖的室内播客录制间。背景是一整面浅色木质嵌入式书架墙，每层层板下方有暖黄色 LED 灯带，柔和地照亮书架；书架上稀疏地摆着几排彩色书脊的书、一个深色陶瓷小摆件、几只玻璃器皿、一个放大镜摆件，右上方挂一幅浅色线条小画。画面左侧前景是一大盆高大的绿植，叶片宽大，右侧角落有一盆小绿植。地面铺浅米色几何纹地毯。两把木扶手棕色皮革单人椅相对摆放，中间是一张米色圆柱形小边几，上面放着两杯清水。光线是温暖自然的室内光，主光柔和，人物脸部清晰，背景轻微虚化，色调暖而克制。

【画面内容】开场空镜：播客间内暂时无人，两把皮椅与中间小边几上的两杯清水入镜，书架灯带暖光稳定，画面完全静止。随后主持人从左侧入座，嘉宾已坐在右侧等待。无人物特写、无运镜，只是一次安静的落座。

【风格】16:9 横屏，专业电影摄影机质感，浅景深，暖色调，写实、克制、电影感，像一档高质量的中文访谈播客现场。人物皮肤与衣物纹理真实，不过度磨皮，无特效字幕。环境保留极轻微室内空气声，无背景音乐。
