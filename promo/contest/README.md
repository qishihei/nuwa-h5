## 作品一 · 思想会客厅

**标题**（可直接复制）
```
思想会客厅 · 25 位大师同时回答你一个问题
```

**一句话简介**
```
负债、辞职、婚姻、35 岁危机——说出来，孔子、芒格、乔布斯、尼采会同时作答，还能多轮追问。
```

**详细介绍**
```
这不是又一个"跟名人聊天"的套壳。

「思想会客厅」把 25 位思想家的认知框架做成了可对话的引擎：孔子讲仁与恕、芒格讲逆向思维、马斯克讲第一性原理、尼采讲成为你自己……你用一句话说出当下的困境，多位大师会同时用自己的框架回答，答案并排对照，观点互相碰撞。

你可以继续追问，也可以换个大师再问一遍，看同一个问题在不同认知体系里会长出什么不同的答案。

产品已完成付费闭环（¥9.9 / ¥19.9 解锁），是真在跑的线上产品，不是 demo。
```

**分类**：内容创作（备选：学习教育）

**体验链接**
```
https://qishihei.github.io/nuwa-h5/promo/thought-salon/landing
```

**封面**：`promo/contest/cover-thought.png`

## 作品二 · 导演会客厅

**标题**
```
导演会客厅 · 25 位导演用镜头语言帮你重看问题
```

**一句话简介**
```
镜头卡住、剧本停滞、风格拿不准——说给诺兰、王家卫、库布里克、黑泽明听，他们用自己的电影语言回答你。
```

**详细介绍**
```
把 25 位导演的电影方法论做成可对话的引擎。

诺兰会跟你讲结构与时间的折叠，王家卫讲情绪与留白，库布里克讲控制与对称，黑泽明讲动势与天气。你说出卡住的地方——一个拍不出来的镜头、一个写不下去的第三幕、一种拿不准的调性——他们会用各自的方式帮你重新看一遍。

同一套交互骨架，完全独立的知识库：问同一个问题，25 位导演会给你 25 种答案。

面向短视频创作者、影视从业者、以及所有需要用"镜头"思考的人。
```

**分类**：内容创作

**体验链接**
```
https://qishihei.github.io/nuwa-h5/promo/director-salon/landing
```

**封面**：`promo/contest/cover-director.png`

## 社媒发帖计划（拿满 +30）

规则拆解：**阅读数 + 收藏数**之和 → 阶梯分；再加 5–20 人气分；必须**公开可见**且**带活动话题**。

| # | 选题 | 配图 | 为什么能拿收藏 |
|---|---|---|---|
| 1 | "我把 25 位大师做成了可以对话的 AI" | 总览海报 `thinkers/00-总览.png` | 产品介绍，信息完整 |
| 2 | "用芒格的逆向思维，回答一次要不要辞职" | 芒格卡片 `cards/charlie-munger.png` | 卡片信息密度高，易收藏 |
| 3 | "同一句话，问孔子和尼采，答案完全相反" | 孔子 + 尼采卡片拼图 | 对照感强，评论区会吵起来 |
| 4 | "35 岁危机，我给 5 位大师各问了一遍" | 5 张卡片九宫格 | 话题自带流量 |
| 5 | "和 25 位导演聊镜头：诺兰会怎么拍这场戏" | 导演卡片九宫格 | 垂直人群精准 |

**每条必做**：公开可见、带比赛话题标签、正文里放体验链接（或评论区置顶）、配图 ≥3 张。
