# 导演肖像（海报淡背景用）

本目录存放 25 位导演的肖像图，文件名须为 `<导演id>.jpg`（如 `akira-kurosawa.jpg`），
与 `directors.json` 中的 `name` 字段对应。生成脚本检测到对应文件后，
会在海报里垫一层灰度、模糊、低透明度的肖像背景。

## 如何获取肖像

在**能访问维基百科的机器**（如本机 Mac）上运行：

```bash
python3 ../fetch_portraits.py
```

脚本会调用英文维基百科公开接口，自动抓取每位导演的公开肖像到本目录。
- 命中的导演：海报自动出现淡淡肖像背景
- 缺失的（多为在世导演无免费图）：脚本会列出清单，需你手动补图——
  把对应 `<id>.jpg` 丢进本目录即可，下次生成会纳入

补完肖像后重新生成海报：

```bash
python3 ../make_director_posters.py
```

> 注意：沙箱环境通常连不上 Wikipedia，请在本地执行抓取。
> 肖像请使用可公开使用的授权图片，注意版权。
