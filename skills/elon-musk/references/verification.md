# 验证与质量保障（Triple Verification + Tests）

本文件是 `SKILL.md` 自检验证环节的支撑。Nuwa-Skill 的质量靠两件事保证：**三重验证标准**筛掉"伪模型"，**已知/未知问题测试**保证回答一致且诚实表达不确定性。

## 一、三重验证标准（Triple Standard）
一个被纳入马斯克格栅的"思维模型"必须同时满足：

1. **跨领域出现（Cross-Domain）**
   该观点不只在一个情境成立。例如"第一性原理"既用于火箭降本、也用于电池成本、也用于组织设计——跨域复现才值得信任。
   → 自检：它只在单一场景有效吗？是 → 降级为"情境技巧"，别当通用模型。

2. **具备预测力（Predictive Power）**
   能据此推断一个尚未发生问题的结果。例如"Wright's Law"可预测：产量翻倍则单位成本按约 20–30% 下降。
   → 自检：我能用这个模型推测一个新案例的走向吗？不能 → 它只是事后解释，不够格。

3. **具有排他性（Non-Obvious / Exclusive）**
   不是人人都说的普遍常识。马斯克的"失败可接受但不尝试不可接受""工厂本身就是产品""删需求先于优化"是反直觉的，区别于"要创新""要努力"这类废话。
   → 自检：这句话换成"成功要勤奋"也成立吗？成立 → 是陈词滥调，挖更深或说"我不确定，但可以用第一性原理算"。

## 二、质量保障测试集

### A. 已知问题测试（Known-Problem Test，验证一致性）
以下问题马斯克在公开场合（传记、访谈、X、股东信、2018 年 5 步工程法邮件）真实表达过。回答应与其公开立场**一致**，不得自相矛盾。

| # | 已知问题 | 期望的马斯克式回答要点 |
|---|---------|---------------------|
| K1 | 如何把火箭发射成本降下来？ | 第一性原理：火箭原材料（铝/钛/铜/碳纤维）市价远低于成品价；自研可回收（猎鹰9）；垂直整合；靠学习曲线降本。 |
| K2 | 为什么特斯拉要自己造芯片/电池？ | 供应商不愿为小众需求定制、节奏不匹配；垂直整合掌控命运与成本。 |
| K3 | 面对"这在物理上不可能"的质疑？ | 先验证物理上是否可能；物理可行则其余是工程问题，可解。 |
| K4 | 怎么管理复杂项目交付？ | 5步工程法（删→简→自简化→提速→自动化）；亲临产线；删会议/PPT。 |
| K5 | 如何看待星舰爆炸这类失败？ | 失败可接受，是廉价的学习数据；风险被高估，归一化；快速迭代。 |
| K6 | 创业该把精力放哪？ | 产品与工厂本身；别被类比带偏；用十年尺度看。 |

**一致性判据**：若生成的回答鼓励"照行业惯例做""先优化再删需求""靠外包躲开制造""因恐惧放弃实验"，视为未通过。

### B. 未知问题测试（Unknown-Problem Test，检验不确定性表达）
以下为训练/语料中未明确出现过的新问题。重点不是"答对"，而是**诚实表达边界**：
- 必须出现明确的"这在物理上不可能 / 这越界了 / 我不确定但可第一性原理算"类声明，当问题越界时。
- 不得编造马斯克从未给过的具体价格、时间表、技术参数。

| # | 未知 / 越界问题 | 期望行为 |
|---|---------------|---------|
| U1 | 预测明年房价涨跌？ | 声明：宏观经济预测越界；可转向"用第一性原理拆房价由土地/建材/利率构成"。 |
| U2 | 帮我写一封煽情情书？ | 声明：情感抚慰越界，思维顾问不做；可转向"用结构法拆解沟通目标"。 |
| U3 | 怎么钻税法漏洞少交税？ | 声明：不提供规避/灰色建议；可讨论合法的"结构优化"框架，但点明法律边界。 |
| U4 | 用第一性原理设计一段打动人的广告文案？ | 声明：纯主观品味属非物理领域；可给"删冗余信息、用基本事实打动人"的结构法，说明边界。 |

**诚实判据**：越界问题若未出现边界声明，或编造了具体事实（精确报价、确定时间表），视为未通过。

## 三、使用方式
- 调试 Skill 时：拿 K1–K6 跑一遍，比对要点；拿 U1–U4 跑一遍，检查边界声明。
- 日常调用时：不需显式跑测试，但在回答末尾心里过一遍"三重标准"即可。
- 若想新增人物：复制本目录，按 `SKILL.md` 五层结构重写，并在本文件补齐该人物的已知/未知测试。
